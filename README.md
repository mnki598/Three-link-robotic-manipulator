# Three-Link 3D Printed Robotic Manipulator

This project involves design, fabrication, assembly, and control of a
three-link robotic manipulator using 3D printing and Arduino-based control.

The system is combined with feedback control simulation to validate
the behavior of the physical robot and compare it with the mathematical model.

---

## Objective
To design a low-cost robotic manipulator and demonstrate:

- Forward and inverse kinematics
- Actuator control using Arduino
- Feedback control
- Simulation vs hardware validation

---

## Hardware Setup
- 3D printed links and joints
- Servo / DC motors
- Arduino controller
- External power supply
- Mechanical assembly

---

## Software Components

### Arduino Code
Low-level motor control and serial communication implemented in Arduino.

### Simulation
MATLAB simulation includes:
- Kinematic modeling
- Feedback control design
- Joint trajectory tracking

---

## Results
The robot successfully:
- Executes joint motion
- Responds to control inputs
- Matches simulation behavior
- Demonstrates feedback control

Plots, images, and videos are available in the `results` directory.
